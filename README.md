# Paradise Nursery Shopping App

A React + Redux shopping app with:
- Landing page with company details and background image
- Product listing page with three categories and six plants per category
- Shopping cart with quantity controls, item deletion, and totals

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Deployment (GitHub Pages)

This repo is configured with Vite `base: '/Paradise-Nursery-Shopping-App/'` for GitHub Pages.
